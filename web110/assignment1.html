IP Addresses and Location

Here is my first assignment! First, I learned what an IP address is and how it can be used to estimate where a device is located. I found my IPv4 address and checked whether I had an IPv6 address as well. Then, I used the KeyCDN IP Location Finder to see what information was connected to my IP address. I learned that it can show general details such as the country, state, city, and sometimes approximate coordinates. This activity helped me understand new vocabulary I did not know before and how websites can use location data. It also made me think more about how much privacy we actually have when using the internet.

Git and Bitbucket

Second, I learned about Git and Bitbucket and how they are used for version control. The tutorials showed me how to create a repository, save changes through commits, and manage files. These activities helped me understand how to create and use my own repository for this class. I also learned how Git and Bitbucket can be used to store, organize, and share code online. Before this class, I did not know much about repositories or how useful they could be when working on coding projects. It is cool to understand the basics of it.

How the Internet Works

Third, I learned more about how the internet works and how devices connect with each other. I didn't know much about what happens behind the scenes when we go online. The internet basics tutorials helped me understand how information travels between devices and across the world. I also learned about different ways to connect to the internet, including Wi-Fi, cable, DSL, and satellite. It was interesting to learn that there are different ways for people to access the internet depending on their location and available technology.

In all, these three activities gave me a better understanding of the internet, how location data works, and how Git and Bitbucket can be used for coding projects.
