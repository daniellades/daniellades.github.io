What I Learned About CSS

In this lesson, I learned how to use CSS to style a website and control its layout. I now understand the differences between inline, internal, and external CSS and when to use each method to format HTML elements. Practicing with properties like colors, fonts, margins, and padding showed me how to make a webpage look cleaner and easier to read. As I continue through this class, I can use these skills in future assignments and even in a future career in business. Learning the basics of web design has also made me more confident using digital tools.
